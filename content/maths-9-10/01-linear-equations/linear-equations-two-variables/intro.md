# Linear equations in two variables

An equation like $2x + 3y = 12$ links two unknowns. Any equation that can be written as

$$ax + by + c = 0 \quad (a, b \text{ not both } 0)$$

is a **linear equation in two variables**.

- A **solution** is a pair $(x, y)$ that makes the equation true. $(6, 0)$, $(3, 2)$ and $(0, 4)$ all solve $2x + 3y = 12$.
- There are **infinitely many** solutions: pick any $x$ and solve for $y$.
- Plot all the solutions and you get a **straight line**. Every point on the line is a solution, and every solution is a point on the line.
