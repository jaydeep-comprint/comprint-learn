## Worked example: factorising with identities

Read each identity from right to left.

**a)** $9x^2 - 16y^2 = (3x)^2 - (4y)^2$, a **difference of squares**: $p^2 - q^2 = (p - q)(p + q)$.
So $9x^2 - 16y^2 = (3x - 4y)(3x + 4y)$.

**b)** $4x^2 + 20x + 25$: the first and last terms are squares, $(2x)^2$ and $5^2$, and the middle term is
$2 \times 2x \times 5 = 20x$. So it is a **perfect square**: $(2x + 5)^2$.
Careful: $4x^2 + 25$ (no middle term) is *not* $(2x + 5)^2$.

**c)** $27x^3 - 8 = (3x)^3 - 2^3$. Use $p^3 - q^3 = (p - q)(p^2 + pq + q^2)$:
$27x^3 - 8 = (3x - 2)(9x^2 + 6x + 4)$. (And $p^3 + q^3 = (p + q)(p^2 - pq + q^2)$.)

**d)** $x^3 + 6x^2 + 12x + 8 = x^3 + 3(x^2)(2) + 3(x)(2^2) + 2^3$, which is $(x + 2)^3$.
