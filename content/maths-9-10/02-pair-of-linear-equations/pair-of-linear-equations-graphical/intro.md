# Pair of linear equations: the graphical method

Two linear equations in the same two variables, such as

$$a_1x + b_1y + c_1 = 0, \qquad a_2x + b_2y + c_2 = 0,$$

form a **pair**. Each equation is a straight line, so a solution of the pair is a point on **both** lines.

| The lines are… | Solutions | Ratio test |
|---|---|---|
| intersecting | exactly one (the meeting point) | $\frac{a_1}{a_2} \ne \frac{b_1}{b_2}$ |
| parallel | none (inconsistent) | $\frac{a_1}{a_2} = \frac{b_1}{b_2} \ne \frac{c_1}{c_2}$ |
| coincident | infinitely many | $\frac{a_1}{a_2} = \frac{b_1}{b_2} = \frac{c_1}{c_2}$ |
