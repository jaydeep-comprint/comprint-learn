# Conditionals

Programs often need to **choose**: do one thing if something is true, and another thing otherwise.

```python
marks = 72
if marks >= 33:
    print("Pass")
else:
    print("Try again")
```

- A **condition** is an expression that is `True` or `False`, such as `marks >= 33`.
- The indented lines under `if` run only when the condition is `True`.
- Compare with `==` (equal), `!=`, `<`, `<=`, `>`, `>=`. A single `=` stores a value; it never compares.
