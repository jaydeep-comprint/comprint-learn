# Algebraic identities

An **identity** is an equality that is true for **every** value of its variables. For example,
$(x + 1)^2 = x^2 + 2x + 1$ holds for $x = 0, 1, -5, 2.5, \ldots$, while the equation $x + 1 = 3$ is true only for $x = 2$.

Each identity below comes from multiplying out brackets, so you don't have to multiply them out every time:

- $(x + y)^2 = x^2 + 2xy + y^2$ and $(x - y)^2 = x^2 - 2xy + y^2$
- $(x + y)(x - y) = x^2 - y^2$
- $(x + a)(x + b) = x^2 + (a + b)x + ab$
- $(x + y + z)^2 = x^2 + y^2 + z^2 + 2xy + 2yz + 2zx$
- $(x + y)^3 = x^3 + y^3 + 3xy(x + y)$ and $(x - y)^3 = x^3 - y^3 - 3xy(x - y)$
- $x^3 + y^3 = (x + y)(x^2 - xy + y^2)$ and $x^3 - y^3 = (x - y)(x^2 + xy + y^2)$
- $x^3 + y^3 + z^3 - 3xyz = (x + y + z)(x^2 + y^2 + z^2 - xy - yz - zx)$

Watch out: $(x + y)^2$ is **not** $x^2 + y^2$, and $(x + y)^3$ is **not** $x^3 + y^3$.
Identities also make mental sums quick: $103 \times 97 = (100 + 3)(100 - 3) = 10000 - 9 = 9991$.
