# Loops

A **loop** repeats a block of code, so you don't have to write the same line many times.

```python
for i in range(3):
    print("Hello", i)    # prints Hello 0, Hello 1, Hello 2
```

- A `for` loop runs once for each value in a sequence, such as `range(...)`.
- A `while` loop keeps running **as long as** its condition is `True`.
- Loops are often used to **accumulate**: add up, count or multiply as you go.
