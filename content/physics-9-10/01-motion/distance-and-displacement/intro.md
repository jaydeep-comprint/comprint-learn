# Distance and displacement

When something moves, we can describe *how much ground it covered* or *where it ended up compared with
where it started*. These are different quantities.

- **Distance** is the total length of the path travelled. It has only a size (it is a *scalar*) and is
  never negative.
- **Displacement** is the straight-line change in position, from the start point to the end point, in a
  stated direction. It has size **and** direction (it is a *vector*).

Both are measured in metres (m). Distance is always greater than or equal to the size of the displacement;
they are equal only when the object moves in one direction along a straight line.
